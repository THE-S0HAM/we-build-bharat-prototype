# Refund Policy — DevCon Events

## Standard Refund Rules

- Full refund if requested more than 14 days before the event
- 50% refund if requested 7-14 days before the event
- No refund if requested less than 7 days before the event
- Free ticket registrations may be cancelled at any time without financial implications

## Exceptions

- Medical emergencies: full refund with documentation, regardless of timing
- Event cancellation by organizer: automatic full refund within 7 business days
- Venue change: attendee may request full refund within 48 hours of change announcement

## Process

1. Attendee submits refund request via event portal or email
2. OrbitOps creates a refund approval request
3. Organizer reviews and approves/declines
4. If approved, refund processed through original payment method
5. Confirmation email sent to attendee

## Notes

- Refund processing is a HIGH_RISK action requiring human approval
- OrbitOps agent will prepare the refund recommendation but never execute without approval
- Transaction reference required for refund verification

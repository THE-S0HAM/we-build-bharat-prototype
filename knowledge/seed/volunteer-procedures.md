# Volunteer Procedures

## Check-In Desk

### Normal Check-In (QR Scan)
1. Attendee shows QR code on phone or printed ticket
2. Volunteer scans QR using the check-in app
3. System verifies QR signature server-side
4. If valid: mark checked in, hand over badge/kit
5. If invalid: try manual search by name/email

### Ticket Recovery
1. If attendee cannot show ticket, open Check-in Recovery
2. Search by registration ID, email, phone, or name
3. If found: system runs verification, generates ticket if all checks pass
4. If not found: ask for payment transaction reference
5. If still not found: create an unresolved recovery case
6. Direct the attendee to the Registration Help Desk

### Important Rules
- NEVER accept verbal confirmation without system verification
- NEVER manually create a registration — only the system can recover tickets
- If the system is down, note the attendee's details and direct them to the Help Desk
- For VIP attendees, contact the Registration team lead immediately

## Emergency Procedures

- Medical emergency: call venue emergency services (posted at each desk)
- Fire alarm: follow venue evacuation plan (maps at each exit)
- Security concern: contact event security lead immediately
